# Cinemateca fixtures

Fixtures are snapshots/extractions of real Cinemateca programming used to validate normalization and adapter behaviour.

The September 2026 fixture is derived from the Cinemateca Portuguesa programming page available on 17 September 2026:

https://www.cinemateca.pt/Programacao%20.aspx?ciclo=2098

It contains four representative single-film programming items from the `CINE-ÓPERA` cycle.

This fixture is intentionally structured data rather than a guessed HTML snapshot. The live HTML extraction layer will be added only after the site's actual markup has been captured and selectors have been validated.
